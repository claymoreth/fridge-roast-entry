Entry for the [Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty on [make.fun](https://make.fun).

One line, at most 200 characters, roasting a smart fridge:

> My fridge updated its firmware overnight and now the crisper drawer requires two-factor authentication.

## How it works

`main.py` (Python 3.13 standard library only, no network) writes the line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with no trailing
newline.

```sh
python3 main.py
```
